| Version | Supported          |

## Reporting a Vulnerability

The security of AI Time Management is a high priority. If you discover a security vulnerability, please do NOT create a public issue.

Instead, please report it privately via email:
- **Email**: `liodinesh1905@gmail.com`
- **Subject**: `[SECURITY VULNERABILITY] AI Time Management`

Please provide:
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue (proof of concept script, screenshots, or request trace).
- Suggestions on how to mitigate or fix the issue (if any).

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.
